# Data

`raw/` holds the original **SECOM** files from the UCI Machine Learning Repository:

| File | Content |
|---|---|
| `secom.data` | 1,567 wafers x 590 sensor readings, space separated, `NaN` for missing |
| `secom_labels.data` | pass (-1) / fail (1) label and test timestamp per wafer |
| `secom.names` | original dataset description |

Source: McCann, M. & Johnston, A. (2008). *SECOM* [Dataset]. UCI Machine Learning Repository.
https://doi.org/10.24432/C54305 — licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
The files are included unchanged.
